# 농구 개인 연습 AI 훈련 계획 에이전트 (웹 MVP)

*Created At: 2026-11-11T03:13:17.263293+00:00*

## Goal

코치 없이 혼자 연습하는 취미·동호회 농구 선수가 무엇을 연습해야 할지 알 수 있도록, 사용자 입력과 지난 연습 기록을 바탕으로 1주 단위 맞춤 훈련 계획을 생성하고, 연습 결과를 다음 주 계획의 난이도에 반영하는 '계획 → 연습 → 기록 → 다음 계획' 순환을 웹에서 제공한다.

## User Stories

1. **As a** 혼자 연습하는 취미·동호회 농구 선수, **I want to** 포지션, 실력 수준(초급·중급·상급), 약점·목표, 가용 시간(주 N일 × 회당 M분), 연습 장소·장비를 입력하고 1주 단위 맞춤 훈련 계획을 받고 싶다, **so that** 무엇을 연습해야 할지 몰라 헤매지 않고, 내 조건에 맞는 연습을 바로 시작할 수 있다.
2. **As a** 혼자 연습하는 취미·동호회 농구 선수, **I want to** 계획의 각 드릴에서 이름, 세트 수, 반복 수, 소요 시간, 드릴별 목적 설명을 보고 싶다, **so that** 코치 없이도 무엇을 얼마나, 왜 해야 하는지 이해하고 연습할 수 있다.
3. **As a** 혼자 연습하는 취미·동호회 농구 선수, **I want to** 연습이 끝난 뒤 슛 드릴은 시도·성공 수를, 드리블·레이업·패스 같은 슛 외 드릴은 '쉬웠음/적당/어려웠음' 자기평가를 직접 입력하고 싶다, **so that** 내 연습 결과가 기록으로 남고 다음 주 계획에 반영된다.
4. **As a** 혼자 연습하는 취미·동호회 농구 선수, **I want to** 지난 주 연습 기록에 따라 다음 주 계획의 난이도가 자동으로 하향·유지·상향되기를 원한다, **so that** 내 실력 변화에 맞춰 너무 쉽지도 어렵지도 않은 연습을 계속할 수 있다.
5. **As a** 혼자 연습하는 취미·동호회 농구 선수, **I want to** 로그인한 계정에 내 연습 기록과 계획이 저장되기를 원한다, **so that** 다음에 접속해도 이전 기록이 이어져 다음 계획에 반영된다.

## Constraints

- 주 사용자는 혼자 연습하는 취미·동호회 선수로 한정한다 (엘리트 학생 선수, 코치·트레이너, 학부모는 MVP 대상이 아니다)
- 사용 형태는 웹 브라우저로 한다
- 기록은 로그인 기반의 사용자별 계정에 저장한다
- 사용 방식은 사후 방식이다. 연습 후 사용자가 기록을 직접 입력하며, 실시간 사용은 지원하지 않는다
- MVP의 기록 입력은 직접 입력만 지원한다 (슛 드릴: 시도·성공 수, 슛 외 드릴: 쉬웠음/적당/어려웠음 자기평가). 영상 업로드·분석은 포함하지 않는다
- 계획 기간은 1주로 고정한다
- 가용 시간은 '주 N일 × 회당 M분' 형태로 입력받는다
- AI(LLM)가 입력(포지션·실력 수준·약점·목표·가용 시간·장소·장비·지난 기록)을 바탕으로 계획 전체를 생성하되, 난이도 조정은 정해 둔 규칙을 반드시 따른다
- 일정 제약: 수 주 안에 데모가 가능해야 한다
- 비용 제약: 비용을 최소화한다. 데모 기간에 AI API는 소액 유료 사용을 허용한다

## Success Criteria

1. 사용자는 웹 브라우저에서 로그인할 수 있고, 사용자별로 계정에 입력 정보·계획·연습 기록이 저장되어 재접속 후에도 조회된다
2. 사용자는 포지션, 실력 수준(초급·중급·상급), 약점·목표, 가용 시간(주 N일 × 회당 M분), 연습 장소·장비를 입력할 수 있다
3. 생성된 계획은 1주 단위이며, 각 드릴에 드릴 이름, 세트 수, 반복 수, 소요 시간, 드릴별 목적 설명이 포함되어 있다
4. 계획의 연습일 수는 사용자가 입력한 주 N일을 넘지 않는다
5. 계획의 각 연습일에 적힌 드릴 시간을 합하면 사용자가 입력한 회당 M분을 넘지 않는다
6. 사용자가 없다고 입력한 장비·장소가 필요한 드릴은 계획에 나오지 않는다 (예: 골대가 없으면 슛 드릴이 포함되지 않는다)
7. 지난 기록이 없는 첫 사용자의 첫 계획 난이도는 사용자가 입력한 실력 수준(초급·중급·상급)을 그대로 따른다
8. 사용자는 슛 드릴에 대해 시도 수와 성공 수를, 슛 외 드릴(드리블·레이업·패스 등)에 대해 '쉬웠음/적당/어려웠음' 자기평가를 입력할 수 있다
9. 슛 드릴의 다음 주 난이도는 1주 동안의 시도·성공 수를 합산한 누적 성공률로 정한다: 40% 미만이면 하향, 40% 이상 60% 미만이면 유지, 60% 이상이면 상향한다 (예: 월 50회 중 10회 + 목 50회 중 30회 = 100회 중 40회 = 40% → 유지)
10. 슛 드릴의 '하향'은 다음 계획에서 슛 거리 축소(3점 라인 → 미드레인지) 또는 제자리슛으로의 변경으로 확인된다 (예: 3점슛 50회 중 10회, 20% 입력 후 다음 계획에서 하향이 확인된다)
11. 슛 드릴의 '상향'은 다음 계획에서 무빙슛·캐치앤슛으로의 변경, 슛 거리 확대(미드레인지 → 3점 라인), 또는 수비 압박·시간 제한 추가로 확인된다
12. 슛 외 드릴의 다음 주 난이도는 1주 동안 가장 많이 나온 자기평가로 정한다: 쉬웠음 → 상향, 적당 → 유지, 어려웠음 → 하향
13. 슛 외 드릴의 자기평가가 동수이면 난이도를 유지한다
14. 계획에 있었지만 그 주에 기록이 하나도 입력되지 않은 드릴은 난이도를 바꾸지 않고, 다음 주 계획에 같은 드릴을 다시 넣어 안내한다

## Assumptions

- 프로젝트 성격(실습용 미니 프로젝트 vs 실제 출시용)은 미정이며, 현재 범위는 '수 주 내 데모' 제약에 맞춰 잡는다
- 비용 최소화와 소액 유료 허용을 함께 고려해, 무료 티어·저비용 AI 모델을 우선 사용하고 필요할 때만 소액 결제까지 쓰는 것으로 해석했다
- 로그인 기반 사용자별 계정은 확정되었으나, 수 주 내 데모 일정을 고려하면 인증 범위가 일정에 부담이 될 수 있다 (인터뷰어 해석)
- AI가 계획 전체를 생성하므로, 가용 시간·장비·장소 조건과 난이도 규칙 준수를 보장하려면 생성 결과를 검증하는 단계가 필요할 것으로 본다 (인터뷰어 해석, 구현 방식은 미확정)
- 난이도 조정 이유 표시(예: '지난 기록 20%를 근거로 조정함')와 드릴 비중·세트 수 증가, 반복 수 감소는 PM이 선택하지 않았으므로 인수 조건에 포함하지 않는다
- 기록이 없는 드릴을 재안내할 때는 난이도 변경 근거가 없으므로 난이도를 그대로 두는 것으로 해석했다
- 1주 누적 기준은 한 번의 기록에 난이도가 흔들리지 않게 하려는 의도로 해석했다
- 초기 질문의 '사후 방식'에 언급된 영상 업로드는 이후 답변에서 기록 직접 입력만으로 좁혀졌으며, 영상 관련 기능은 MVP 밖으로 본다
